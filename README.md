
# Library OOP

## Overview

A Java learning project developed to practice object-oriented programming (OOP) and explore how to organize an application's structure and program flow.

## Learning Objectives

* Practice object-oriented programming concepts in Java.
* Organize application components into separate classes.
* Improve code readability and maintainability.
* Understand how different parts of an application interact.

## Technologies Used

* Java
* Object-Oriented Programming (OOP)

## Project Structure

The application source code is organized under the `src` directory.

## Getting Started

1. Clone the repository.
2. Open the project in IntelliJ IDEA or another Java IDE.
3. Configure the Java Development Kit (JDK).
4. Run the application's main class.

## Purpose

This project was created for learning and practice, with a focus on Java programming, object-oriented design, and application structure.
